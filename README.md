# Rainy Day Algorithms: JavaScript
This repository contains solutions for coding practice problems. Additionally, you 
will find some unit tests to accompany the solutions.

# Setup
This project uses node.js.
The unit-testing framework we use is Mocha.

There are some notes below on basic setup and how to run the tests. For a more complete explanation, please check out this article: https://rainydayalgorithms.com/blog/javascript-setup

## General setup
You will need node and node package manager (npm) set up on your device. Once you confirm that you have node on your computer, run the following command in your project's folder to install all necessary packages for this repository:

```npm install```

## Unit tests
Before you can run the unit tests, first check that you have Mocha installed.

```npm install mocha```

To run the tests, execute the following command in your terminal

```npm test```

If you want to change the command, you can. Test-command setup is in the `package.json` file in the `scripts` section.
